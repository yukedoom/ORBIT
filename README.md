# ORBIT

モノクローム基調のシンプルなブラウザミニゲーム集です。単一の HTML ファイルで構成されており、GitHub Pages などの静的ホスティングで動作します。

## 収録ゲーム

### 1. オセロ
通常のオセロに加え、必殺技ルールやオンライン対戦に対応しています。

* **対戦モード**
  * 2人プレイ（ローカル）
  * VS AI（かんたん / ふつう / つよい）
  * オンライン対戦
* **必殺技ルール（あり / なし 切替可）**
  * **メテオ**（CD:2）：選んだ1石を破壊（5回目以降はシールドごと破壊するスーパーメテオ）
  * **スティール**（CD:2）：相手のシールドなし石を1つ奪う
  * **スナイプ**（CD:2）：挟めなくても空きマスに1石置ける
  * **シールド**（CD:3）：自分の石を裏返らなくする（盤上3つまで）
  * ※ 1手目の駒が動く前・試合終了後のみ切り替え可能です（オンライン時はホストのみ操作可）。
* **オンライン対戦機能**
  * 5文字の部屋コードで作成・参加・再入室・破棄が可能
  * 相手のオンライン／離席状態の表示（緑／灰ランプ）
  * ミニチャット＆対局ログ表示（履歴のスクロール閲覧に対応）
  * 待機部屋の自動削除および24時間の有効期限管理に対応

### 2. 数当て
1〜1億の中からランダムに選ばれた数字を当てるミニゲームです。

## 動作環境・UI
* PC（2カラム）／スマートフォン（1カラム）のレスポンシブ対応
* OS設定に連動したライト／ダークモード自動切替

## セットアップ（オンライン対戦を使う場合）
ローカル対戦・AI対戦・数当てはそのまま動作します。オンライン対戦を利用する場合は Firebase の設定が必要です。

1. Firebase プロジェクトを作成し、**Authentication（匿名ログイン）** と **Realtime Database** を有効化する。
2. HTML 内の `FIREBASE_CONFIG` にプロジェクトの設定値を記入する。
3. Realtime Database のセキュリティルールを設定・公開する。
